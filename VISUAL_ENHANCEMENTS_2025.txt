CHANGE 4: Special Case - Inherited ARTIGO
═══════════════════════════════════════════════════════════════════════════════════════

EXCEL INPUT:
┌────────┬─────────────────────┬──────┬──────────────┐
│ ARTIGO │ DESCRIÇÃO           │ UN   │ QT           │
├────────┼─────────────────────┼──────┼──────────────┤
│ 1      │ Chapter             │      │              │
│ 1.2    │ Demolições          │      │              │  ← Article (parent)
│ 1.2.1  │ Incluir entulho     │      │              │  ← Comment text
│        │ Paredes interiores  │ m2   │ 50.00        │  ← Item (inherits 1.2.1)
│        │ Incluir entulho     │      │              │  ← Comment text
│        │ Transporte incluído │      │              │  ← Comment text
└────────┴─────────────────────┴──────┴──────────────┘

HOW IT WORKS:
1. Row "1.2.1" (Incluir entulho) has no UN/QT → Stored as comment with artigo "1.2.1"
2. Row with "Paredes interiores" has UN/QT but NO ARTIGO → Inherits "1.2.1"
3. Subsequent comment rows continue under "1.2.1"

RESULT IN DATABASE:
Item:
  artigo: "1.2.1"          ← Inherited from lastCommentArtigo
  descricao: "Paredes interiores"
  un: "m2"
  qt: 50.00
  item_comments: "Incluir entulho\nIncluir entulho\nTransporte incluído"
                 ↑ All comments from 1.2.1 and parent 1.2

DISPLAYED AS:
┌─────────────────────────────────────────────────────────────┐
│ ▼ 1.2 - Demolições                                         │
├─────────────────────────────────────────────────────────────┤
│ Incluir entulho                      ← Text                │
│                                                             │
│ ┌───────────────────────────────────────────────────────┐   │
│ │ ARTIGO │ DESCRIÇÃO        │ UN │ QT               │   │
│ ├────────┼──────────────────┼────┼──────────────────┤   │
│ │ 1.2.1  │ Paredes inter... │ m2 │ 50.00            │   │
│ │        │ [💬 Comments]    │    │                  │   │  ← Hover shows
│ └───────────────────────────────────────────────────────┘   │  all comments
│                                                             │
│ Incluir entulho                      ← Text                │
│ Transporte incluído                  ← Text                │
└─────────────────────────────────────────────────────────────┘
